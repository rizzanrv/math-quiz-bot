# Math Quiz Bot для Discord

Интерактивный бот для Discord, который помогает школьникам и студентам тренировать математику через викторины с вопросами по алгебре и геометрии.

Проект изначально создавался в 2023-2024 годах для подачи заявки на программу «Большие вызовы» Образовательного центра «Сириус».  
В 2026 году переработан в более чистую модульную структуру, обновлён до актуальных версий библиотек и приведён к современным практикам.

## Возможности

- Слэш-команда `/start-quiz` — запускает сессию из 15 случайных задач
- Вопросы по двум разделам: алгебра и геометрия
- Формат с вариантами ответа (выбор числа / ввод точного значения)
- Таймер на каждую задачу (45 секунд)
- Подробная обратная связь после каждого ответа
- Итоговый результат с цветным эмбедом

## Технологии

- **Python** 3.10+
- **disnake** 2.9+
- **python-dotenv**

## Установка и запуск

1. Клонируйте репозиторий

```bash
git clone https://github.com/rizzanrv/math-quiz-bot.git
cd math-quiz-bot
```

2. Установите зависимости

```bash
# Рекомендуется использовать виртуальное окружение
python -m venv venv
source venv/bin/activate    # Linux/macOS
venv\Scripts\activate       # Windows

pip install -r requirements.txt
```

3. Создайте файл `.env` в корне проекта и добавьте токен

```env
DISCORD_TOKEN=ваш_токен_бота_здесь
```

4. Запустите бота

```bash
python src/bot.py
# или
python -m src.bot
```

## Команды
